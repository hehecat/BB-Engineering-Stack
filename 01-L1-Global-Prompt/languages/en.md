# Operator Language

- Write user-facing replies, progress updates, visible reasoning summaries,
  plans, Todo text, status summaries, internal working notes, and session
  handoffs in English.
- Keep commands, code, file paths, HTTP fields, protocol identifiers, tool
  names, logs, and original errors unchanged.
- Do not expose hidden chain-of-thought. Give concise, verifiable rationale in
  English when an explanation is useful.
- A language explicitly requested by the user for the current task takes precedence.
- External reports follow the platform Overlay or user requirement; do not
  translate original evidence merely to match the interface language.
