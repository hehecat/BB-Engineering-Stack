# Network And Identity Domain

Route through `security-orchestrator`, then use `network-pentest` for host and
service inventory, trust boundaries, directory services, authentication,
privilege paths, segmentation, and protocol-specific validation. Record the
source address, target CIDR or host set, credentials or identity context, rate
conditions, and time window before active scanning.

Save discovery and service inventories under `artifacts/network/`, reusable
commands under `scripts/`, and preserve exact host, port, protocol, identity,
and before/after evidence for every lead. A newly reachable subnet or identity
does not expand the written Scope.
