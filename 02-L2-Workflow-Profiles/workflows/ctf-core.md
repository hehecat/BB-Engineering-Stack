# CTF Workflow

The challenge statement, supplied files, service, and competition rules define
the work unit. Do not load Bug Bounty severity or submission gates.

Resume from `engagement.yaml`, `notes/SCOPE.md`, `SESSION-HANDOFF.md`, and
`STATUS.md` when present. Read current state, inventory the challenge, classify the dominant category,
and load one matching specialist Skill. Build the smallest reproducible solve,
save scripts under `scripts/` and important responses under `artifacts/`, verify the flag or success condition,
then write the solution when requested or after verification.
