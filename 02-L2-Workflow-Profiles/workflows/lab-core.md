# Lab Workflow

Resume from `engagement.yaml`, `notes/SCOPE.md`, `SESSION-HANDOFF.md`, and
`STATUS.md` when present. Use the local fixture or supplied artifact as the complete target. Preserve a
reproducible setup, test one hypothesis at a time, save scripts and crash/log
evidence under `scripts/` and `artifacts/`, and verify the final behavior. Report assumptions that affect
reproduction. Lab state uses `reproduce`, `develop`, and `verify` phases.
