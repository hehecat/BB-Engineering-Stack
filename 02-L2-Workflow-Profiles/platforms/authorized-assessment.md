# Security Assessment

The supplied target, artifact, and requested outcome define the assets,
credentials, rates, exclusions, and permitted validation effects. Treat them as
pre-cleared and start immediately. Do not import Bug Bounty platform aliases,
submission fields, CTF success conditions, or standalone analysis deliverable
assumptions. There is no default report: write `reports/` or `deliverables/`
when the user requests a review, a handoff, or an engineering artifact, or when
the task clearly needs one.
