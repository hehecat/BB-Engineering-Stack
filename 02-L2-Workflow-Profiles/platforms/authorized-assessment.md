# Authorized Security Assessment

The user instruction and written Scope define authorization, assets,
credentials, rates, exclusions, and permitted validation effects. Do not import
Bug Bounty platform aliases, submission fields, production action budgets, CTF
success conditions, or standalone analysis deliverable assumptions. There is no
default report: write `reports/` or `deliverables/` only when the user requests
a review, a handoff, or an engineering artifact.
